# Sink 0.2.20: UI clarity and safety

UI-only release. No sync, storage, networking, conflict, or replication behavior changed. Tag: `0.2.20`, without a `v` prefix.

## Status

- The status bar uses `Sink ✓` when connected and no longer claims reviews are waiting.
- Floating labels use plain status words: Connected, Syncing, Review, Blocked, Disconnected.
- Activity reads `Sending file` or `Receiving file`; the overlay is decorative and hidden from assistive technology.
- Paused has its own warning treatment instead of disconnected grey.

## Review and diffs

- The diff starts collapsed; clicking a file row or focusing its name and pressing Enter opens it.
- The footer summarizes effective Local/Remote decisions and destructive deletions before applying.
- Destructive applies ask for confirmation; blocked rows are excluded from selection counts.
- Bulk actions report rows skipped because a side is unavailable.
- Fold expansion keeps keyboard focus visible; Escape returns focus to the file row.
- Local/Remote terminology and change-count grammar are consistent.

## Settings and setup

- Server examples use the actual `5985` port.
- Setup URI copy warns that credentials and passphrase are readable.
- Rebuild local database confirms destructive loss and reports when sync is not running.
- Setup directions confirm what may be overwritten; Push then Pull is described honestly.
- Setup failure states that transfers may be partial and offers Retry, Change direction, or Close.
- Snapshot terminology, partial restore warnings, role labels, version formatting, and refresh states are clearer.

149 unit/DOM tests pass, typecheck/build pass, and the full isolated E2E suite passes 9/9. Rendered desktop/narrow light/dark review screenshots were inspected. See [0.2.20 verification](../verification/0.2.20.md).
