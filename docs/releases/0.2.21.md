# Sink 0.2.21: recovery from blocked sync

UI/recovery release. Sync algorithms are unchanged. Tag: `0.2.21`, without a `v` prefix.

## Recovery actions

- **Settings → Sink → Troubleshooting** shows the current sync state and whether work is pending.
- **Review issues** reopens the existing pull/review path for deferred changes, retained conflicts, or a blocked retry.
- **Restart sync** stops and starts the engine with the current settings.
- **Resolve pending sync issues** is also available in the command palette.
- Blocked and paused status tooltips now point to this recovery path.

If a review is already open, apply or cancel it first. These actions do not bypass safety decisions.

## Compatibility

Install all three assets together. Keep **Sync config folder** off while testing. The grey-screen, mobile, and historical-plaintext limits are unchanged.
