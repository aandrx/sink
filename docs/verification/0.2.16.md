# 0.2.16 verification evidence

Branch: `release/0.2.15-sync-reliability`. Patch release for the IndexedDB lifecycle error observed after installing 0.2.15.

## Incident

The user saw:

`Sink: Sync failed — Failed to execute 'transaction' on 'IDBDatabase': The database connection is closing.`

followed by `Sink: Done` and `Sink: Failed to start — ... database connection is closing.`

Source inspection identified a restart race:

- PouchDB caches one IndexedDB connection per database name.
- `SyncEngine.shutdown()` could close the cached connection while a replacement engine was already starting.
- Startup work also ran outside the operation queue, so shutdown could close the database while `start()` was still using it.

Both are addressed. This is a source diagnosis and regression-tested repair; the user's exact BRAT reload sequence has not yet been repeated on their live vault.

## Fixes

- `shutdown()` waits for an in-progress `start()` after cancellation, then drains the operation queue before closing.
- LocalDB tracks the newest instance for each database name. An older instance closing does not close the shared connection when a replacement already owns it.
