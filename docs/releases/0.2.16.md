# Sink 0.2.16: IndexedDB lifecycle fix

Patch release for 0.2.15. Tag: `0.2.16`, without a `v` prefix.

## Fix

Sink could show:

`Failed to execute 'transaction' on 'IDBDatabase': The database connection is closing.`

This happened when a plugin restart or reload overlapped the previous engine's shutdown. PouchDB caches one IndexedDB connection per database name, so the old instance could close a connection already in use by its replacement.

- Engine shutdown now waits for an in-progress startup pull and reconciliation before releasing the database.
- Only the newest LocalDB instance closes the shared IndexedDB connection. An older instance stopping does not interrupt a replacement instance.
- The fix is covered by restart-order regressions, and all prior 0.2.15 behavior remains.

## Compatibility

Install all three assets together: `main.js`, `manifest.json`, and `styles.css`. Use the same build on every device because Sink's version gate compares exact versions.

Upgrade every device from 0.2.15 to 0.2.16 before syncing. Back up the vault, including configuration, and CouchDB first. Keep config-folder sync off while testing.

The grey-screen cause remains unconfirmed. The live-vault and historical-plaintext limitations from 0.2.15 are unchanged. See [0.2.15 release notes](0.2.15.md) and [verification evidence](../verification/0.2.16.md).
