# Sink 0.2.17: IndexedDB teardown fix

Patch release for the remaining `database connection is closing` error on plugin restart/reload. Tag: `0.2.17`, without a `v` prefix.

## Fix

PouchDB caches one IndexedDB connection per database name. Sink was still closing that shared connection during engine shutdown, which could interrupt a replacement plugin instance that had already opened the same database.

- Engine shutdown no longer closes the shared IndexedDB connection.
- PouchDB keeps the cached connection for the replacement instance.
- Shutdown still waits for an in-progress startup and for queued work before releasing the engine.
- Explicit local-database rebuild still destroys the database.
- LocalDB direct-close and pending-startup regressions cover the lifecycle.

## Compatibility

Install all three assets together: `main.js`, `manifest.json`, and `styles.css`. Use the same build on every device because Sink's version gate compares exact versions.

Upgrade every device to 0.2.17 before syncing. Back up the vault, including configuration, and CouchDB first. Keep config-folder sync off while testing.

The grey-screen and historical-plaintext limitations are unchanged. See [0.2.17 verification evidence](../verification/0.2.17.md).
