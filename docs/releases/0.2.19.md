# Sink 0.2.19: stable conflict resolution

Patch release for retained-conflict reviews that failed with an unreviewed leaf arriving during retirement. Tag: `0.2.19`, without a `v` prefix.

## Fix

- Live replication is paused when a review contains retained conflict revisions.
- The reviewed leaf set cannot change while the user decides.
- Replication resumes after the review is applied or cancelled.
- Deleted tombstone leaves no longer block retirement.
- Live, unreviewed content leaves still fail closed.

## Compatibility

Install all three assets together: `main.js`, `manifest.json`, and `styles.css`. Use the same build on every device.

No further local database rebuild is needed after 0.2.18 unless the local cache is still broken. Keep **Sync config folder** off while validating sync.

The grey-screen and historical-plaintext limitations are unchanged. See [0.2.19 verification](../verification/0.2.19.md).
